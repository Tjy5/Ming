# Illustrative geography asset

`geography.ts` is a repository-owned, hand-authored vector layer for the eight
regions currently returned by the governance API. It includes an irregular
coastline/landmass silhouette, river lines, and region boundaries so the map
reads as a geographic surface rather than a card grid. The paths are an
illustrative historical reconstruction, not a claim of modern administrative
or historically exact boundaries. No runtime map tiles, external images,
fonts, or network assets are used.

Version: `map-geography-v1`.
