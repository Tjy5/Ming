# Minister Portrait Files

Put manually generated portrait images in this folder:

- `frontend/public/portraits/`

The frontend now loads local files only and does **not** call `/api/minister/portrait`.

Required filenames:

- `wei_zhongxian.png` -> 魏忠贤
- `xu_guangqi.png` -> 徐光启
- `sun_chengzong.png` -> 孙承宗
- `yuan_chonghuan.png` -> 袁崇焕
- `zhou_yanru.png` -> 周延儒
- `wen_tiren.png` -> 温体仁
- `lu_xiangsheng.png` -> 卢象升
- `yang_sichang.png` -> 杨嗣昌

Recommended image specs:

- Aspect ratio: `1:1`
- Size: `512x512` or `1024x1024`
- Format: `PNG`
