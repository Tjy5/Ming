# 调研 03：玩家反馈与评测

- **日期**：2026-08-07
- **核心矛盾**：一边挨骂、一边停不下来——次日留存 75.1%、非工作日平均在线约 7 小时，同时好评率 54%-58%（https://zhuanlan.zhihu.com/p/2042377430527206187）

## 一、好评点（附原文）

1. **自由与蝴蝶效应的惊喜感**
   - "高度的自由化和真实感，也让玩家体会到了那段历史风云变幻中，做为崇祯的无奈和艰难。游戏创新的接入了AI推演，让玩家实现了历史上诸多的意难平"（Steam 讨论帖 https://steamcommunity.com/app/4304230/discussions/0/572666202100372808/）
   - "由于AI带来的无限可能，还是非常有代入感和趣味的"（知乎回答）
   - 玩家社区名场面：修仙雷劈皇太极、70 小时攀科技造出原子弹、请伽利略托里拆利入朝（游戏那点事）
2. **题材契合与代入感**
   - "明末本来就是中文互联网最适合做历史推演的题材之一……玩家天然会带着问题进场：魏忠贤该不该杀？袁崇焕该不该用？要不要迁都？要不要议和？海禁能不能开？……这些问题本身就像一个个开放式Prompt"（罗斯基 https://zhuanlan.zhihu.com/p/2048384535696500060）
   - "从版面风格到人物图片，整个游戏风格古风化，非常契合游戏的历史背景"（Steam 讨论帖）
3. **策略深度被玩家认可**
   - 知乎高赞通关长文（"我尽力了"档，25 年打通关）总结出完整的执政心法：财政先行、招叛杀叛、六部比内阁重要、改革有窗口期、永远抓住主要矛盾（财政→救灾→叛军→后金）——证明系统具备可挖掘的策略深度（https://www.zhihu.com/question/2004918435499501395）
   - "AI会挖坑"（督粮总安排能力不足的人，顾此失彼）被玩家当作拟真博弈而非纯 bug（知乎回答）
4. **对比传统策略游戏的差异化价值**
   - 3DM 试玩："AI大模型驱动下的明末政局……牵一发而动全身，即便有一处想要锐意改革，也会四处掣肘……但倘若能在这种情况下完成破局，其成就感也定然不是寻常游戏可比"（https://www.3dmgame.com/original/3745943.html）
   - "它试图把AI接进一套策略游戏系统里——诏书会改变国库、民心、军队、党争、地方局势和官员关系"（罗斯基）
5. **UI/完成度**："制作精良的UI、庞大的内容量"（罗斯基，作为"商业上非常失败"的反衬说明）

## 二、差评点（附原文）

1. **Token 收费（最大差评源）**
   - "3个回合就要20块？"（游民星空标题 https://www.gamersky.com/news/202605/2142683.shtml）
   - "steam评论区第一页除了个别几楼之外都在骂"（游民星空）
   - "本体买断 + token 内购的双重付费模式……直接导致了游戏舆情的失控，评论区充满了恶评和退款tag"（罗斯基）
   - "我还以为花48买本体游戏，结果游戏内还有内购是个啥？"（Steam 讨论帖标题）
   - 核心不满：外接 API 诉求被拒（"玩家只需要用48元买个游戏框架"的预期落空），官方改为自定价出售 token（游民星空）
2. **AI 幻觉与记忆混乱（第二大差评源）**
   - 长对话触发"准奏"时记忆串题："命令量产燧发枪，最终自动生成的指令或许就会变成'开始建设工厂''拨20万两开仓赈灾'"（游戏那点事）
   - 文本与面板不一致："文本里说某个政策执行了，面板数据却没变；大臣在剧情里被罢免了，下一回合还在朝堂上发言；战争结果刚写完，下一次推演又被'改口'"（罗斯基，附曹化淳时间线错乱截图）
   - 已死人物仍可对话，AI"找补"说玩家"发动了魔法卡死者苏生"或"假死辞官"（游戏那点事）
   - 多回合政令无法自动持续："工部尚书告诉你技术需要一年，你最好每个回合都去询问一遍"（游戏那点事）
3. **历史准确性质疑（知乎问题题干）**
   - 知乎问题描述点名："游戏设定过于阴谋论，缺少明史专家参考，天启七年，全国赋税平均缴纳率4%（疑为游戏数值）"（https://www.zhihu.com/question/2004918435499501395，题干原文如此，细节存疑）
   - AI 史实错误："官员在崇祯刚登基时讲出'大顺'这样的诡异现象"（3DM 试玩）
   - AI 文风模板化："很多角色滥用'不是XX……而是XXX！'这样的语句，令人产生疲倦感，俗称'八股'"（3DM 试玩）
4. **体验与稳定性**
   - "游戏后期，AI每个回合推演结果都要读取大量文本时，出现Bug的机率有增无减"（游戏那点事）
   - "【服务端异常】闪退 无法游玩"（Steam 讨论帖标题）
   - 玩家集中吐槽"稳定性、扣费、Bug 和 AI 推演的不确定性"（品玩专访）
5. **对商业模式与制作组的不信任**
   - "你想多了 一个脸官方群里都不能讨论游戏问题的制作组只想着捞一票就走"（Steam 讨论回帖，指控存疑）
   - "游戏是好游戏，但如果制作组只是想被收够就继续吃相难看吧"（Steam 讨论帖标题）
   - "巨饼无限期"——对官方开放 API/创意工坊承诺不买账（游民星空）

## 三、社区讨论要点

- **Steam 讨论帖《谈谈此游戏的成功之处和失败》**（https://steamcommunity.com/app/4304230/discussions/0/572666202100372808/）：
  - 成功：API 模型接入的自由代入感、古风化 UI、AI 推演实现历史"意难平"
  - 失败/前景：算力计费是最大制约；"已经习惯于买断式游戏体验的玩家在尝鲜后，不得不放弃该游戏……剩下的玩家也会因为算力的支出，而疲劳"
  - 建议：官方与模型供应商深度合作做包月/包年；或自研模型后买断制"终生免费使用，哪怕价格高点"
  - 回帖争议：网易旗下工作室传言；官方群禁讨论问题的指控
- **官方回应**（网易新闻 https://www.163.com/dy/article/KSSE64570526D8LR.html）：开放自定义 API + 创意工坊；承认"低估了玩家对模型自由度和成本控制的需求"；官方托管保留；后续优化"决策反馈、状态衔接以及长流程推演稳定性"
- **行业讨论**（罗斯基）："玩家想要不可预测，但不想要不可靠""游戏的本质是规则，而大模型的本质是概率""太自由，就不稳定；太约束，又失去AI的意义；模型太强，成本高；模型太弱，体验崩"
- **外媒视角**（NEXWORLD https://nexworld.wiki/en/ai-games/chongzhen-simulator/）："players complain endlessly, yet can't stop playing"（玩家边骂边玩）；评价为里程碑级实验品

## 四、玩家行为画像（对 Ming 有意义）

- 玩家会**反复开档**（知乎答主三个档才打通）——重开是玩法一部分，开局策略（"开局必须拿下魏忠贤但别杀，派去守陵""六部比内阁重要"）成为社区知识
- 玩家会**对话式推进科技**（蒸汽机卡密封问题→"让AI到南洋找橡胶最后还是成功了"）——把研究做成可交互过程而非纯数值
- 玩家会**抄作业**：诏书模板、开局保姆教学视频（B 站 BV1NBL76NEmz）——内容传播性强
- 结局系统（庙号/评分/未来推演）成为晒档社交素材（知乎"穿越评分 98"回答获 17 赞）
