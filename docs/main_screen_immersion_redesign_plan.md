# 主界面沉浸式全景大战略重构方案 (Main Screen Immersion Redesign Plan)

## 1. 概述与设计愿景 (Overview & Vision)

将《元末纪事》的主游戏界面从传统的**固定三栏/四格挤压布局**重构为**沉浸式全景大战略 HUD 架构（Crusader Kings 3 风格）**：
- **地图全景沉浸**：天下地图（`RegionMap`）作为核心舞台，占据除顶部资源栏外的 100% 视口，支持全屏视野与自由省份点选。
- **朝廷管理帘幕化**：中右侧的派系、大臣、朝议、官职面板改造为**右侧悬浮折叠抽屉（Slide-over Drawer）**，平时收拢，点击提手平滑滑出。
- **事件栏轻量化（CK3 风格）**：去除笨重的底部卡片事件栏，改为**左下角半透明单行/双行文字大事记（Toast Feed）** + **顶部/右上角待办事项小徽章（Alert Badges）**。
- **圣旨台弹窗化（非全屏宣纸卷轴）**：底部输入区收拢为浮动的 `[ 📜 御笔草诏 ]` 按钮，点击在屏幕中央展开精致的**非全屏宣纸圣旨台（Imperial Edict Modal）**，支持自然语言与快捷政令，集成玉玺落印动效。
- **推进月份印章化**：右下角独立悬浮的金色/朱砂印章按钮 `[ ⏳ 推进月份 ]`。

## 3. 详细模块设计与改造方案 (Component Specifications)

### 3.1 布局与外壳重构 (`App.tsx`, `App.css`, `app-core.css`)
- **网格重构**：`.game-layout` 移除 `grid-template-rows: 56px 1fr 250px`，改为 `56px 1fr`。
- **全屏地图容器**：`.main-area` 与 `.map-workspace` 铺满剩余全部宽度与高度。
- **HUD 图层系统**：
  - `z-index: 10`：全景地图与省份交互底板
  - `z-index: 30`：悬浮 HUD（左下文字流、右下行动按钮、右侧抽屉把手）
  - `z-index: 50`：右侧朝廷抽屉展开帘幕 / 省份详情侧栏
  - `z-index: 100+`：圣旨台弹窗、奏折批阅、剧情事件与全局模态框

---

### 3.2 右侧朝廷抽屉 (`CourtDrawer.tsx`)
- **定位与表现**：
  - 常驻右侧边缘的 3 个竖排标签提手：`📜 派系`、`👥 大臣`、`🏛️ 朝议`。
  - 点击任意标签，抽屉平滑滑出（宽度 `380px`），展示对应的管理面板（`FactionPanel` / `MinisterPanel` / `CourtAssemblyView` / `MissionPanel` / `OfficialRankModal` 触发入口）。
  - 抽屉采用宣纸米白半透明质感（`rgba(246, 239, 224, 0.94)` + `backdrop-filter: blur(10px)` + 暗金细边框）。
  - 支持快捷键 `ESC`、点击右上角关闭按钮或点击地图空白区域一键收起。

---

### 3.3 CK3 风格消息与待办系统 (`Ck3Alerts` + `Ck3EventFeed.tsx`)
- **A. 紧急待办徽章（Alert Badges）**：
  - 挂载在顶部资源栏右侧或左上角。
  - `[ 📜 奏折待批 (N) ]`：带红点未读提示，点击直接呼出奏折批阅模态框。
  - `[ 🚨 阻断剧情 (N) ]`：关键剧情待决提示，点击立即呼出事件决策。
- **B. 底部文字大事记（Event Feed / Toast Ticker）**：
  - 放置在屏幕左下方，半透明悬浮。
  - 展示最近 1~3 条天下大事与政令结算反馈（单行格式：`[纪年/分类] 事件标题/简报`）。
  - 点击单条消息可展开查看富文本详情（`Markdown` 叙事）。
  - 包含 `[史册]` 按钮，点击可查看完整历史记录（`history_log`）。

---

### 3.4 御笔圣旨台弹窗 (`ImperialEdictModal.tsx`)
- **召唤入口**：
  - 地图右下方的悬浮按钮 `[ 📜 御笔草诏 / 下达圣旨 ]`。
  - 快捷键支持：按键盘 `Space` 或 `E` 键一键呼出。
  - 地图联动：在地图上选中省份时，按钮提示自动变为 `[ 📜 向【两淮】下旨 ]`。
- **弹窗视觉与尺寸**：
  - 居中悬浮，尺寸约为 `宽 700px × 高 520px`（非全屏，留出周围地图背景）。
  - 古风宣纸黄绫卷轴装裱设计，竖排抬头“奉天承运皇帝诏曰”。
- **功能集成**：
  - **分类标签**：🏛️ 内政 / ⚔️ 军事 / 🤝 外交 / 👥 人事。
  - **自由自然语言输入**：宣纸质感文本框，支持玩家自由书写口语/文言政令（AI 解析模式）。
  - **快捷政令选择**：点选增税、减税、征兵、赈灾、惩治等常规政令。
  - **省份/官员绑定**：自动带入已选地图省份或指定大臣。
  - **御批落印动画**：点击“颁布诏书”时，触发原汁原味的朱砂大印从天而降、墨晕扩散与盖印音效，随后自动关闭并执行政令。

---

### 3.5 右下角月份推进印章 (`MonthAdvanceControl.tsx`)
- **独立悬浮在屏幕右下角**。
- 显示当前纪年与下一月份（如 `至正十二年 三月 ➔ 四月`）。
- 点击后播放水墨旋转微光动画，进入结算与月推进。
- 如果处于跑团模式（`phase === 'life_story'`），自动显示跑团胶囊 `[ 🎲 当前篇章：濠州起兵 · 进入跑团 ]`。

## 4. 实施阶段与步骤 (Implementation Phases)

### 阶段一：样式与布局底座重构
1. 重写 `App.css` 与 `app-core.css`，将 `.game-layout` 改为全屏地图 HUD 架构。
2. 确保 `RegionMap` 自适应 100% 容器宽高，保留省份高亮与点击事件。

### 阶段二：抽屉与悬浮组件开发
1. 创建/提取 `CourtDrawer.tsx`（封装派系、大臣、朝议右侧抽屉）。
2. 创建 `Ck3EventFeed.tsx`（左下角文字消息流）与 `Ck3Alerts.tsx`（紧急待办徽章）。
3. 改造/创建 `ImperialEdictModal.tsx`（非全屏宣纸圣旨台弹窗）。

### 阶段三：App.tsx 组装与状态连接
1. 在 `App.tsx` 中整合全屏地图、右侧抽屉、CK3 消息流、圣旨台和推进印章。
2. 对接地图点击选中省份（`targetRegion`）向圣旨台的自动填充流转。
3. 对接 `phase === 'life_story'` 时的跑团入口展示。

### 阶段四：测试验证与品质打磨
1. 运行并更新前端单元测试（`desktop-command-surface.test.tsx` 等）。
2. 运行 `npm run type-check` 与 `npm test` 保证类型与功能无回归。
3. 调优宣纸透明度、滑入滑出过渡曲线与视觉动效。

## 5. 验收标准 (Acceptance Criteria)
- [ ] 主界面没有任何固定的底部 250px 白条与固定的右侧 30% 分栏。
- [ ] 天下地图在顶栏下方 100% 铺满，视觉宽广。
- [ ] 点击右侧提手可平滑展开/收起朝廷管理抽屉。
- [ ] 左下角显示轻量化单行/双行事件消息，点击可看详情。
- [ ] 点击底部 `[ 📜 御笔草诏 ]` 弹出精致的非全屏宣纸卷轴弹窗，支持自由输入与快捷政令并带盖印动效。
- [ ] 右下角月推进按钮在政令下达与月推进时状态正常。
- [ ] 所有既有功能（奏折、朝议、剧情事件、跑团模式、存档、AI 设置）无缝运作，测试全部通过。
